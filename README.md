# Analysing heatwaves

## Description
Python package for analysing heatwave index data (e.g. TX90 HWF, as defined by Perkins & Alexander 2013).

## Key features
- Read heatwave data (indices, maximum temperature) from .nc files (may be gzipped).
- Plot heatwave data.
- Analyse trends in heatwave data.
- Conduct climatology.
- Conduct empirical orthogonal function (EOF) analysis.
